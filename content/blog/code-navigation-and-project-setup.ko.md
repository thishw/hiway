Oh My OpenAgent(OMO)를 시험해 hiway-kit에 적용할 코드 탐색 기능을 골랐습니다. 11월 18일 기준 저장소 릴리스인 v5.7.1의 `code-intel`은 설치된 ast-grep으로 코드 구조를 검색하고, 규칙이 의도대로 매치되는지 확인하고, 변경을 미리 보여줍니다. 지원하는 언어 서버를 필요할 때 호출할 수도 있습니다. `session-history`는 지정한 로컬 Codex·Claude Code 세션 로그에서 이전 결정을 찾습니다.

## v5.8.0에 예정된 변경

**여러 소스 파일에 걸친 C/C++ 정의·참조 조회.** 지원하는 컴파일 데이터베이스(`compile_commands.json`)가 있는 프로젝트에서 킷의 clangd 도구로 조회하면 자동으로 인덱스를 만듭니다. 서버는 조회할 때만 실행하며, 프로젝트 밖 사용자 전용 캐시에 저장한 인덱스를 다음 조회에서 다시 씁니다. 인덱스 범위를 확인할 수 없거나 제한 시간 안에 조회를 마치지 못하면, 찾은 결과를 반환하고 일부만 확인됐다고 표시합니다.

**프로젝트가 쓰던 구조와 도구를 따릅니다.** 계획은 프로젝트가 정한 위치에 저장하며, 계획 폴더를 새로 만들기 전에는 묻습니다. 테스트와 문서는 기존 배치를 따릅니다. 검증은 프로젝트에 정의된 명령과 이미 설치된 도구를 쓰며, 필요한 의존성이 없으면 그 사실을 알립니다. 포매터는 프로젝트 설정을 따르고, 설치 도구는 전역 Git 템플릿을 설정하기 전에 묻습니다.

이 글을 쓰는 시점에 v5.8.0은 출시 대기 중입니다. 저장소 마켓플레이스는 v5.7.1을 제공하며, Anthropic의 Claude Code 디렉토리는 v5.7.1 심사 중이라 v5.5.1을 제공합니다. Codex의 저장소 마켓플레이스 설치는 [시작하기](/ko/docs/getting-started/#codex)를 참고하세요. 현재 저장소 릴리스는 [변경 기록](/ko/changelog/)에서 확인할 수 있습니다.
